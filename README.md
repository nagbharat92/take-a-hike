# Take a Hike

**[Play in your browser](https://nagbharat92.github.io/take-a-hike/)**

A quiet, pixel-art hiking demo built with Godot. Generate a new mountain trail,
walk its paths and stone stairs, or zoom out to explore the whole route.
Each hike has its own forest scenery and background mountain. No audio.

## Controls

| Key | Action |
| --- | --- |
| A/D or left/right arrows | Walk |
| W/S or up/down arrows | Climb or descend stairs |
| O | Toggle Overview |
| R | Generate a new hike |
| T | Replay the current hike |
| Mouse wheel or +/- | Zoom |
| Esc | Pause or resume |

Credits are available from the pause and overview panels.

## Run and build

See [BUILDING.txt](BUILDING.txt) for Godot setup, asset preparation, and web export.
The source checkout requires separately obtaining the licensed character and
forest packs. Their restricted source artwork is not included here; the hosted
game includes the artwork needed to play.
